# Cursor Origin

Coolify can deploy a private [Cursor Origin](https://cursor.com/origin) repository over SSH. Add the same deploy key to Coolify and Origin, then create the application as a private repository with a deploy key.

## 1. Add a deploy key to Coolify

1. In the Coolify dashboard, open **Keys & Tokens**.
2. Select **Private keys**, then click **+ Add**.
3. Generate a new SSH key or paste an existing private key.
4. Save the key.

Keep the private key available for the next step. Origin needs the same key that you saved in Coolify.

## 2. Add the key to Origin

From the repository directory, run:

```bash
origin ssh-key add
```

Follow the Origin CLI prompts to add the SSH key that you saved in Coolify.

## 3. Add the repository to Coolify

1. Open your project in Coolify and click **+ New**.
2. Select **Private Repository (with deploy key)**.
3. Choose the server that will run the application.
4. Select the private key that you added in step 1.
5. Enter the repository's SSH URL and continue.
6. Configure the application, then deploy it.

<Callout type="info" title="Use the SSH repository URL">

The deploy key authenticates an SSH connection. An HTTPS repository URL will not use it.

</Callout>

For general build and application settings, see [Applications](/applications).
